# Parent Information Handbook Directory

All markdown (`.md`) files stored in this directory are automatically loaded by the Swentonelli Dashboard backend and displayed under the **Parent Info** tab of the **Admin Dashboard** (`/admin`).

### Adding New Parent Information
1. Create a new `.md` file in this folder (e.g. `emergency-contacts.md`, `sports-schedules.md`, `chores-and-allowance.md`).
2. Add a `# Heading 1` at the top of the file to serve as the document title.
3. Write standard Markdown with bullet points, links, bold text, and callouts (`>`).
4. The document will instantly appear in the Admin Dashboard!
