### Technical Implementation

#### Step 1: Locate & Update Avatar Assets
* **Files to Inspect/Modify**: 
  * Look for SVG icons or local image assets: `src/assets/images/avatars/` or `public/images/avatars/`.
  * If the system uses a library like **Lucide React**, **FontAwesome**, or custom SVG components for icons:
    * **Brighton (Tuba)**: Source a high-quality, clean SVG of a Tuba. Since Lucide does not have a native `tuba` icon, write/import a custom SVG path wrapper component or use an open-source SVG.
    * **Benjamin (Creeper)**: Source an 8-bit green Minecraft Creeper SVG or pixel-art PNG and place it in the public assets directory.
* **Modifications**:
  * Save `creeper.svg` (or `creeper.png`) to `public/avatars/benjamin-creeper.png`.
  * Save `tuba.svg` to `public/avatars/brighton-tuba.svg` or register it in the icon utility library.
