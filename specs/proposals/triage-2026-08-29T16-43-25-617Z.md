# Clustered Implementation Proposals

## Cluster 1: UI & Dashboard Display (Child Status Badge Standardization)

### User Feedback Summary (Issue #13)
The children's status badges (e.g., location indicators like "At Mom's"/"At Dad's" and calendar statuses like "No School") currently sit horizontally, causing columns to expand/contract and shift the layout dynamic when calendar events update. 

The requested fixes are:
1. **Vertical Stacking**: Stack status badges vertically instead of rendering them inline side-by-side.
2. **Deterministic Priority**: The housing location badge (At Mom's / At Dad's) must always be at the top of the stack.
3. **Fixed Uniform Width**: Set all badges to a consistent, standardized width equal to the maximum possible badge size to eliminate layout "jumping" when switching calendars or updating states.
4. **Content Alignment**: Keep the icon left-aligned, with the text left-aligned immediately following the icon, leaving any extra trailing space on the right of the badge container.

---

### Proposed Action Items

#### 🛠️ Technical Modifications

1. **Locate Badge Render Components**:
   - Inspect components rendering children status lists (e.g., `ChildCard.tsx`, `ChildHeader.tsx`, or `StatusBadge.tsx`).
   
2. **Refactor Layout and Sorting**:
   - Change the badge container's layout wrapper from a horizontal layout (`flex-row`, `inline-flex`) to a vertical flex stack:
     ```css
     display: flex;
     flex-direction: column;
     gap: 0.25rem; /* tight gap for vertical badge stacks */
     align-items: flex-start;
     ```
   - Implement a deterministic sort function on the array of active badges before mapping:
     ```typescript
     const sortedBadges = [...badges].sort((a, b) => {
       // Location badges (At Mom's, At Dad's) take highest priority (first)
       const isALocation = a.type === 'location' || a.text.includes("Mom's") || a.text.includes("Dad's");
       const isBLocation = b.type === 'location' || b.text.includes("Mom's") || b.text.includes("Dad's");
       if (isALocation && !isBLocation) return -1;
       if (!isALocation && isBLocation) return 1;
       return 0; // Maintain natural order for remaining badges
     });
     ```

3. **Establish Uniform Badge Width & Text Alignment**:
   - Set a constant, explicit width for all badges (e.g., `width: 120px` or `w-28`/`w-32` in Tailwind) that comfortably accommodates the longest badge string ("At Mom's" / "At Dad's" / "No School") without clipping.
   - Configure badge interior styles to left-align components with trailing space:
     ```css
     display: flex;
     align-items: center;
     justify-content: flex-start;
     width: 120px; /* Uniform width */
     text-align: left;
     ```
