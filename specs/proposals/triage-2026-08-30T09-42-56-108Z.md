### Implementation Proposal

#### Category: UI & Dashboard Display

> [!NOTE]
> **Goal:** Simplify the "Talk to the Beagle" dialog interface by removing wordy instructions and renaming the primary submission action to provide a cleaner, distraction-free mobile experience.

##### 1. Streamline "Talk to the Beagle" Dialog Copy
*   **User Request:** Remove the wordy subtitle starting with "dictate or type ...", eliminate the "tap the microphone" footer text, and change the submit button label to "OK".
*   **Technical Changes Required:**
    1.  Locate the dialog component rendering the "Talk to the Beagle" interface.
    2.  Remove the `<p>` or `<span>` element containing the subtitle text (e.g., `"dictate or type..."`).
    3.  Locate and remove the footer text rendering helper instructions like `"tap the microphone to start"`.
    4.  Identify the submit/upload button element and replace its current text label (e.g., `"Upload to the Beagle"`, `"Send"`, or `"Submit"`) with `"OK"`.
    5.  Ensure layout constraints remain visually balanced on narrow viewports (down to `320px` width) now that the extra helper text block has been stripped.

*   **Files to Inspect/Modify:**
    *   `src/components/TalkToBeagleModal.tsx` (or matching modal/dialog component file, e.g., `BeagleFeedbackDialog.tsx`, `TalkToBeagle.tsx`)
    *   Review any localized/string configuration files if the interface text is managed via an i18n or config dictionary.

*   **Verification Steps:**
    1.  Launch the local development server and open the dashboard on a mobile viewport simulator (`430x775` representing iPhone).
